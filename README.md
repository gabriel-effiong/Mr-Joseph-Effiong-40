# Mr Joseph Effiong @ 40

A responsive static milestone/tribute website for the 40th birthday anniversary on 27 October 2026.

## Important before public launch

The included forms use browser `localStorage` as a demo so the site works immediately without a backend. **Do not treat this as a production submission system**: each visitor's submissions stay only in that visitor's browser.

For a real launch, connect the forms to Supabase (recommended) and add an admin dashboard/approval workflow.

## Quick hosting

This is a plain HTML/CSS/JS site and can be deployed directly to Vercel, Netlify or GitHub Pages.

### Vercel
1. Upload/push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Other.
4. Build command: leave empty.
5. Output directory: `.` (or leave default for static site).
6. Deploy.

No Node server is required for this demo build.
